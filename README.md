#  Virtual Lab Assistant

##  Overview

Virtual Lab Assistant is an Electron-based desktop application that helps students with coding, laboratory work, and technical learning using Artificial Intelligence. The application integrates both cloud-based and local AI models to provide real-time assistance.

##  Objectives

* Assist students in coding and laboratory activities.
* Provide AI-powered learning support.
* Offer both online and offline AI assistance.
* Create an interactive desktop learning platform.

##  Key Features

* User Registration and Login
* Secure Authentication System
* Gemini AI Chatbot
* Llama 3 Local Text Generator
* Real-Time Coding Assistance
* AI-Based Learning Support
* Desktop Application Interface
* Offline AI Processing through Ollama

##  Technology Stack

### Frontend

* Electron.js
* HTML5
* CSS3
* JavaScript
* Axios

### Backend

* Python
* Flask
* Flask-CORS

### Artificial Intelligence

* Google Gemini API
* Ollama
* Llama 3

### Process Management

* Node.js Child Process

## ⚙️ Working Flow

1. User launches the Electron application.
2. Electron starts Flask backend services.
3. Ollama launches the Llama 3 model locally.
4. User registers or logs in.
5. User interacts with Gemini AI Chatbot.
6. User generates content using Llama 3.
7. AI responses are displayed through the desktop interface.
